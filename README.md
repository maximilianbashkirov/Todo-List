# Todo-List
небольшой pet-проект с функционалом листа для задач (подсмотрено у Яндекса)

Это приложение «Список дел» (Todo List) — учебный проект на React + TypeScript, полностью на русском языке.

Что умеет
Добавить задачу — ввести текст в поле и нажать «Добавить» или клавишу Enter. Пробелы по краям автоматически обрезаются, пустые задачи не добавляются.
Отметить выполнение — клик по чекбоксу: текст зачёркивается и бледнеет.
Удалить задачу — кнопка «Удалить» убирает её из списка.
Показать статистику — три счётчика внизу: Всего / Выполнено / Осталось.
Когда задач нет, вместо списка показывается надпись «Список пуст. Добавьте первую задачу!», а блок статистики скрывается.

Важные особенности
Всё в памяти. Состояние живёт в useState внутри App.tsx:7. Ни localStorage, ни бэкенда нет — при перезагрузке страницы все задачи исчезают.
Стили — инлайновые через объект в src/styles.ts (тёмный градиент, шрифт DM Sans). Отдельных CSS-файлов нет.
Сборка — webpack (dist/bundle.js + index.html).

Структура
```
src/
├── index.tsx            точка входа, ищет <div id="root"> в index.html
├── App.tsx              состояние + обработчики add/toggle/delete
├── types.ts             интерфейс Todo { id, text, completed }
├── styles.ts            все CSS-стили как CSSProperties
└── components/
    ├── TodoInput.tsx    поле ввода + кнопка
    ├── TodoList.tsx     <ul> со списком или пустое состояние
    ├── TodoItem.tsx     одна задача: чекбокс, текст, кнопка удаления
    ├── TodoStats.tsx    три счётчика
    └── index.ts         barrel-реэкспорт
```
Данные идут однонаправленно: App владеет массивом todos, передаёт его вниз как пропсы вместе с колбэками, а дети только вызывают onToggle(id) / onDelete(id) — то есть поднятие состояния наверх, как и задумано в задании про state-machine.

Установка:

```bash
npm install
```

Скрипты которые нужно проверить:

```bash
npm run build      # Build for production
npm run test       # Run unit tests
npm run lint       # Run ESLint
npm run type-check # Run TypeScript type checking
```

Запуск локально:

1) cd /диркторию проекта/
2) npm run test:all     # проверить работу тестов 
3) npx webpack serve --mode development         # на http://localhost:3000/
